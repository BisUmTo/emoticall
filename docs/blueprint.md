# **App Name**: EmotiCall

## Core Features:

- Webcam Activation: Initiate device webcam stream on button click with permission request.
- SOS Button: SOS BUTTON screen to activate the screenshot capture
- Snapshot Capture: Capture a frame from the live webcam stream upon user action.
- Facial Emotion Analysis: Send the captured image to OpenAI API to analyze the facial expression and infer the predominant emotion; the tool will make the decision to send or not.
- Emotion Display: Display emotion analysis results to the user in a clear manner.

## Style Guidelines:

- Intense red (#E63946) for the main call-to-action button to signify urgency and importance.
- Light, desaturated pastel red (#F1D4D7) to keep the focus on the central button.
- Soft orange (#F4A261) for any secondary interactive elements to provide a visual contrast without diminishing the intensity of the primary red.
- Use a bold, sans-serif font for the 'Call for Help' text to ensure readability and immediate comprehension in emergency situations.
- A clear and universally recognized warning symbol on the main button to further reinforce the app's purpose.
- Subtle fade-in/out transitions when displaying emotion analysis results to create a smooth user experience.
